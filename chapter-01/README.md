## ۱. خلاصه مبانی متالورژیکی و کنترل کیفیت

عیار آهن کل ($Fe_{Tot}$) به‌تنهایی هرگز بیانگر رفتار فرآیندی کانسنگ در خردایش، پرعیارسازی مغناطیسی و پخت گندله نیست. متالورژی مدرن نیازمند پایش توأمان فازهای اکسیدی، درجه مارتیتیزاسیون و عناصر مزاحم است:

1. **مگنتیت ($Fe_3O_4$):** فاز مغناطیسی فرومغناطیس، با قابلیت بازیابی آسان در شدت پایین ($LIMS$) و واکنش گرمازای اکسیداسیون در فرآیند پخت:

   $$
   4Fe_3O_4 + O_2 \rightarrow 6Fe_2O_3 + \Delta H
   $$

2. **مارتیت / هماتیت ($Fe_2O_3$):** کانی‌های پارامغناطیس ضعیف که جدایش آن‌ها معمولاً به شدت مغناطیسی بالاتر یا روش‌هایی مانند فلوتاسیون نیاز دارد و می‌توانند موجب کاهش ضریب مغناطیسی ($MF$) شوند.

3. **گوتیت / لیمونیت ($FeO(OH)$):** دارای تخلخل بالا، جذب رطوبت قابل‌توجه و $LOI$ بالا (افت حرارتی) است و افزایش آن می‌تواند بر رفتار و استحکام گندله خام اثر منفی داشته باشد.

4. **عناصر مزاحم ($P$, $S$, $Na_2O+K_2O$):** فسفر و گوگرد از عناصر مهم در کنترل کیفیت خوراک و محصول فولادی هستند و قلیایی‌ها در کوره احیا می‌توانند موجب تشکیل چرخه‌های داخلی و مشکلات عملیاتی شوند.

## ۲. کارگاه‌های عملی چهارگانه با داده‌های صنعتی

### 📊 ۲.۱. کارگاه اکسل (Excel Hands-on)

**هدف:** غربالگری خودکار محموله‌های ورودی بر اساس حدود کیفی تعریف‌شده برای گرید احیای مستقیم (DR-Grade).

#### مراحل

1. فایل [Data_Ch01_Ch02.xlsx](https://github.com/SoloSenor/IronOre-Pelletizing-QC-Book/blob/main/chapter-01/Data_Ch01_Ch02.xlsx) را باز کرده و به شیت `Ch01_Feed_Mineralogy_Chemistry` بروید.

2. روی ستون `Magnetic_Factor_MF` ابزار **Conditional Formatting → Highlight Cells Rules** را اعمال کنید:

   * مقادیر کمتر از **85%**: نارنجی
   * مقادیر کمتر از **80%**: قرمز

3. در ستون وضعیت، فرمول منطقی زیر را برای ارزیابی انطباق نمونه‌ها پیاده‌سازی کنید:

```excel
=IF(AND(K2<=0.035,M2<=0.06,I2>=85),"Pass",IF(OR(K2>0.045,M2>0.08,I2<80),"Reject","Warning"))
```

**تفسیر وضعیت‌ها:**

| وضعیت     | مفهوم                                              |
| --------- | -------------------------------------------------- |
| `Pass`    | نمونه در محدوده پذیرش تعریف‌شده قرار دارد.         |
| `Warning` | نمونه از حدود هدف فاصله گرفته و نیازمند بررسی است. |
| `Reject`  | نمونه حداقل یکی از حدود رد را نقض کرده است.        |

### 📈 ۲.۲. کارگاه مینی‌تب (Minitab Process Capability)

**هدف:** تحلیل قابلیت فرآیند ($C_{pk}$) برای ناخالصی فسفر ($P%$) در برابر حد بالایی مشخصات فروش فولادسازی:

$$
USL = 0.035\%
$$

#### مراحل در Minitab

1. ستون `P_pct` را از فایل اکسل کپی کرده و در ستون `C1` مینی‌تب قرار دهید.

2. از مسیر زیر استفاده کنید:

**Stat → Quality Tools → Capability Analysis → Normal**

3. در بخش **Data is arranged as** گزینه **Single column** را انتخاب کنید.

4. متغیر `P_pct` را به‌عنوان ستون داده انتخاب کنید.

5. در صورت استفاده از زیرگروه‌های تک‌نمونه‌ای، اندازه زیرگروه را `1` وارد کنید.

6. در قسمت **Upper spec (USL)** مقدار زیر را وارد کنید:

```text
0.035
```

7. تحلیل را اجرا کنید.

#### تفسیر مهندسی

مقدار $C_{pk}$ میزان قابلیت فرآیند را نسبت به نزدیک‌ترین حد مشخصات نشان می‌دهد. در این مثال، چون فقط **USL** تعریف شده است، تمرکز اصلی بر توانایی فرآیند برای قرارگرفتن در زیر حد بالایی فسفر است.

> **نکته:** مقدار $C_{pk}<1.33$ را بهتر است به‌عنوان نشانه نیاز به بررسی و بهبود قابلیت فرآیند تفسیر کرد، نه به‌عنوان اثبات «ناپایداری» فرآیند. **پایداری** فرآیند باید جداگانه با نمودارهای کنترل بررسی شود.

### 🐍 ۲.۳. کارگاه پایتون (Python Data Science)

**هدف:** استخراج ماتریس همبستگی پیرسون بین متغیرهای شیمیایی، شاخص‌های کانی‌شناسی و شاخص‌های مرتبط با کیفیت.

#### کد پایتون

```python
import pandas as pd
import seaborn as sns
import matplotlib.pyplot as plt

# 1. بارگذاری داده از فایل اکسل
excel_path = "../shared-datasets/Data_Ch01_Ch02.xlsx"

df = pd.read_excel(
    excel_path,
    sheet_name="Ch01_Feed_Mineralogy_Chemistry"
)

# 2. انتخاب متغیرهای کلیدی
features = [
    "Fe_Tot",
    "FeO",
    "Satmagan",
    "Magnetic_Factor_MF",
    "LOI",
    "P_pct",
    "Alkalis_Na2O_K2O",
    "Cake_Moisture_Impact"
]

corr_matrix = df[features].corr(method="pearson")

# 3. ترسیم نقشه حرارتی
plt.figure(figsize=(10, 8))

sns.heatmap(
    corr_matrix,
    annot=True,
    cmap="vlag",
    fmt=".2f",
    vmin=-1,
    vmax=1
)

plt.title(
    "Correlation Matrix: Mineralogy vs Quality KPIs (SMIC)",
    fontsize=14
)

plt.tight_layout()

# 4. ذخیره خروجی
plt.savefig(
    "outputs/ch01_correlation_heatmap.png",
    dpi=300,
    bbox_inches="tight"
)

plt.show()
```

#### خروجی مورد انتظار

نقشه حرارتی ایجادشده امکان بررسی سریع روابط خطی بین متغیرها را فراهم می‌کند. مقدار ضریب همبستگی پیرسون در بازه زیر قرار دارد:

$$
-1 \leq r \leq +1
$$

که در آن:

* $r \approx +1$ : همبستگی خطی مثبت قوی
* $r \approx 0$ : نبود شواهدی از همبستگی خطی قابل‌توجه
* $r \approx -1$ : همبستگی خطی منفی قوی

> **نکته:** همبستگی پیرسون به‌تنهایی بیانگر رابطه علّی نیست و در صورت وجود روابط غیرخطی، داده‌های پرت یا توزیع‌های نامناسب باید با احتیاط تفسیر شود.

### 📉 ۲.۴. کارگاه پاور بی‌آی (Power BI Dashboard)

**هدف:** ساخت داشبورد کنترل کیفیت برای نمایش شاخص‌های کلیدی عملکرد (KPI) و شناسایی نمونه‌های خارج از حدود مشخصات.

#### مراحل

1. فایل اکسل را در Power BI بارگذاری کنید:

**Home → Get Data → Excel**

2. شیت زیر را انتخاب کنید:

```text
Ch01_Feed_Mineralogy_Chemistry
```

3. پس از بارگذاری داده، Measureهای محاسباتی زیر را ایجاد کنید.

#### میانگین فاکتور مغناطیسی

```DAX
Average_MF =
AVERAGE(
    'Ch01_Feed_Mineralogy_Chemistry'[Magnetic_Factor_MF]
)
```

#### تعداد نمونه‌های با فسفر بالاتر از حد مشخصات

```DAX
High_P_Samples_Count =
CALCULATE(
    COUNTROWS(
        'Ch01_Feed_Mineralogy_Chemistry'
    ),
    'Ch01_Feed_Mineralogy_Chemistry'[P_pct] > 0.035
)
```

#### پیشنهاد ویژوال‌های داشبورد

برای نمایش نتایج می‌توان از ویژوال‌های زیر استفاده کرد:

| ویژوال                     | شاخص پیشنهادی                          | کاربرد                                   |
| -------------------------- | -------------------------------------- | ---------------------------------------- |
| **Gauge**                  | `Average_MF`                           | نمایش میانگین فاکتور مغناطیسی            |
| **Card**                   | `High_P_Samples_Count`                 | تعداد نمونه‌های دارای فسفر بالاتر از USL |
| **Table**                  | نمونه‌ها + شاخص‌های شیمیایی            | بررسی جزئیات نمونه‌ها                    |
| **Conditional Formatting** | `P_pct` و `Magnetic_Factor_MF`         | شناسایی سریع نمونه‌های بحرانی            |
| **Column Chart**           | `P_pct` برحسب محموله/نمونه             | بررسی تغییرات فسفر                       |
| **Scatter Chart**          | `Fe_Tot` در برابر `Magnetic_Factor_MF` | بررسی رابطه عیار آهن و رفتار مغناطیسی    |

#### تنظیم Gauge

برای ویژوال **Gauge** مربوط به `Average_MF`:

* **Value:** `Average_MF`
* **Target Value:** `85`
* **Minimum:** `70`
* **Maximum:** `100`

> در صورتی که `Magnetic_Factor_MF` در داده‌ها به‌صورت اعشاری بین `0` و `1` ذخیره شده باشد، مقادیر هدف نیز باید به‌صورت `0.85`، `0.80` و ... تعریف شوند. واحد و مقیاس ستون باید قبل از طراحی داشبورد بررسی شود.
