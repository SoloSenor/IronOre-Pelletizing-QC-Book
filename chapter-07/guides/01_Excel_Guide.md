# ۱. ساختار پیشنهادی داده

برای جلوگیری از تداخل مراجع سلولی، فرض می‌کنیم:

| ستون | متغیر         |
| ---- | ------------- |
| A    | `Timestamp`   |
| C    | `P80_Micron`  |
| D    | `FeO_Percent` |
| E    | `EWMA_P80`    |
| F    | `UCL_P80`     |
| G    | `LCL_P80`     |
| H    | `Y_t`         |
| I    | `CUSUM_Plus`  |
| J    | `CUSUM_Minus` |
| K    | `Alarm`       |

ردیف‌های 2 تا 101 شامل 100 مشاهده Phase I هستند.

# ۲. پارامترهای Phase I

یک بخش پارامتر در مثلاً محدوده `M2:N8` ایجاد کنید:

| سلول | پارامتر      | مقدار |
| ---- | ------------ | ----: |
| M2   | `P80_Mean`   |  75.0 |
| M3   | `P80_StdDev` |   2.0 |
| M4   | `Lambda`     |  0.20 |
| M5   | `EWMA_L`     |   3.0 |
| M6   | `FeO_Mean`   |  1.50 |
| M7   | `FeO_StdDev` |  0.08 |
| M8   | `CUSUM_K`    |  0.25 |
| M9   | `CUSUM_H`    |   5.0 |

در حالت واقعی بهتر است میانگین و انحراف معیار از داده Phase I محاسبه شوند.

### میانگین P80

```excel
=AVERAGE(C2:C101)
```

### انحراف معیار P80

```excel
=STDEV.S(C2:C101)
```

اگر داده‌های Phase I واقعاً مستقل نباشند، صرفاً محاسبه `STDEV.S` برای تعیین حدود SPC ممکن است کافی نباشد و ساختار خودهمبستگی باید بررسی شود.

---

# ۳. محاسبه EWMA

## ردیف اول — E2

$$
Z_1=\lambda X_1+(1-\lambda)\mu_0
$$

فرمول Excel:

```excel
=$M$4*C2+(1-$M$4)*$M$2
```

## ردیف‌های بعدی — E3

```excel
=$M$4*C3+(1-$M$4)*E2
```

سپس فرمول را تا انتهای داده Fill کنید.

---

# ۴. حدود EWMA

## UCL — سلول F2

```excel
=$M$2+$M$5*$M$3*SQRT(($M$4/(2-$M$4))*(1-(1-$M$4)^(2*ROWS($C$2:C2))))
```

## LCL — سلول G2

```excel
=$M$2-$M$5*$M$3*SQRT(($M$4/(2-$M$4))*(1-(1-$M$4)^(2*ROWS($C$2:C2))))
```

این فرمول‌ها را تا انتهای داده Fill کنید.

---

# ۵. استانداردسازی FeO برای CUSUM

در ستون `H`:

```excel
=(D2-$M$6)/$M$7
```

این مقدار:

$$
Y_t=\frac{X_t-\mu_0}{\sigma_0}
$$

را محاسبه می‌کند.

---

# ۶. CUSUM مثبت

در `I2`:

```excel
=MAX(0,H2-$M$8)
```

در `I3`:

```excel
=MAX(0,I2+H3-$M$8)
```

و سپس تا انتها Fill کنید.

---

# ۷. CUSUM منفی

در `J2`:

```excel
=MAX(0,-H2-$M$8)
```

در `J3`:

```excel
=MAX(0,J2-H3-$M$8)
```

و سپس Fill کنید.

---

# ۸. آلارم

در `K2`:

```excel
=IF(
OR(
E2>F2,
E2<G2,
I2>$M$9,
J2>$M$9
),
"ALARM",
"NORMAL"
)
```

سپس Conditional Formatting را برای مقدار `ALARM` فعال کنید.

---

# ۹. نکته مهم درباره آلارم

آلارم EWMA یا CUSUM به معنی:

> «فرآیند نسبت به baseline تغییر کرده است»

و نه:

> «لاینر حتماً ساییده شده است»

برای بررسی سایش لاینر باید شواهد دیگری مانند:

* P80
* Specific Power
* Return Load
* Feed Hardness
* Feed Rate
* وضعیت مکانیکی آسیاب

نیز بررسی شوند.

---

# ۱۰. نمودار EWMA

یک Line Chart بسازید و موارد زیر را نمایش دهید:

* `P80_Micron`
* `EWMA_P80`
* `UCL_P80`
* `LCL_P80`

همچنین می‌توان Phase I/II را با یک خط عمودی در مشاهده 100/101 مشخص کرد.

---

# ۱۱. نمودار CUSUM

برای CUSUM نموداری شامل موارد زیر بسازید:

* `CUSUM_Plus`
* `CUSUM_Minus`
* خط افقی `H = 5`

عبور CUSUM از حد تصمیم باید به‌عنوان **سیگنال بررسی** ثبت شود.

---

# ۱۲. تفاوت Control Limit و Decision Limit

در EWMA:

`UCL/LCL` حدود کنترل هستند.

در CUSUM:

`H` حد تصمیم CUSUM است.

این دو مفهوم از نظر محاسبات و تفسیر یکسان نیستند و نباید با specification limit محصول جایگزین شوند.
