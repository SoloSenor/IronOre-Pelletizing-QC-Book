# ۱. آماده‌سازی Phase I

پیش از اجرای نمودار، 100 مشاهده اول به‌عنوان Phase I در نظر گرفته می‌شوند.

هدف Phase I:

* بررسی ثبات اولیه؛
* تخمین `μ₀`؛
* تخمین `σ₀`؛
* شناسایی نقاط غیرعادی پیش از ساخت baseline.

> اگر Phase I خود دارای علل ویژه یا تغییر رژیم عملیاتی باشد، استفاده مستقیم از آن برای baseline می‌تواند نامناسب باشد.

# ۲. EWMA برای P80

مسیر معمول:

`Stat → Control Charts → Time-Weighted Charts → EWMA`

متغیر:

`P80_Micron`

تنظیمات آموزشی:

* Weight `λ = 0.20`
* Historical mean `μ₀ = 75`
* Historical standard deviation `σ₀ = 2`
* حدود کنترل با ضریب `L = 3`

اگر نسخه Minitab مورد استفاده منوی متفاوتی داشته باشد، نام دقیق گزینه‌ها ممکن است کمی متفاوت باشد؛ منطق تنظیمات باید حفظ شود.

---

# ۳. تفسیر EWMA

اگر EWMA به‌صورت پایدار به سمت بالا حرکت کند، این می‌تواند نشان‌دهنده تغییر تدریجی میانگین P80 نسبت به baseline باشد.

اما این نتیجه به‌تنهایی علت تغییر را مشخص نمی‌کند.

برای بررسی فرضیه سایش لاینر، هم‌زمان بررسی کنید:

* `SpecificPower_kWht`
* `ReturnLoad_th`
* `FeedHardness_Index`
* `FeedRate_th`

---

# ۴. CUSUM برای FeO

مسیر:

`Stat → Control Charts → Time-Weighted Charts → CUSUM`

متغیر:

`FeO_Percent`

پارامترهای آموزشی:

* Target = `1.50`
* Historical σ = `0.08`
* Reference value `K = 0.25`
* Decision interval `H = 5`

CUSUM مثبت برای پایش افزایش FeO و CUSUM منفی برای پایش کاهش FeO استفاده می‌شود.

---

# ۵. بررسی Lag مشعل و FeO

فرض آموزشی:

`BurnerZoneTemp_C`

ممکن است با تأخیر زمانی روی:

`FeO_Percent`

اثر بگذارد.

برای بررسی این موضوع باید Lagهای مختلف آزمایش شوند.

برای مثال:

* Lag 0
* Lag 1
* Lag 2
* ...
* Lag 12

و سپس:

* correlation؛
* cross-correlation؛
* نمودار زمانی؛
* و در صورت نیاز مدل رگرسیون با Lag

بررسی شود.

> بیشترین correlation الزاماً به معنی وجود رابطه علّی نیست.

---

# ۶. چرا نباید مستقیماً بگوییم «Lag = 6 ساعت»؟

اگر دیتاست مصنوعی عمداً یک Lag شش‌ساعته ایجاد کرده باشد، این مقدار برای آموزش قابل مشاهده است.

اما در داده واقعی، Lag باید از خود داده‌ها و دانش فرآیند استخراج شود.

بنابراین عبارت صحیح:

> «در دیتاست آموزشی، یک Lag شش‌ساعته برای بررسی رابطه مشعل و FeO در نظر گرفته شده است.»

و نه:

> «اثر مشعل همیشه شش ساعت بعد در FeO دیده می‌شود.»

# ۷. مقایسه با Shewhart

برای مقایسه روش‌ها می‌توان سه نمودار را بررسی کرد:

* Individuals/Shewhart
* EWMA
* CUSUM

هدف این مقایسه نشان دادن تفاوت **حساسیت آماری به شیفت‌های کوچک** است.

نباید صرفاً بر اساس اینکه یک نمودار زودتر هشدار داده، آن را به‌عنوان «بهتر» معرفی کرد؛ نرخ هشدار کاذب و مشخصات طراحی نمودار نیز باید در نظر گرفته شوند.

---

# ۸. ARL

یکی از معیارهای مهم طراحی نمودارهای SPC، Average Run Length یا ARL است.

به‌صورت مفهومی:

* `ARL₀` = طول متوسط دنباله تا هشدار در حالت تحت کنترل
* `ARL₁` = طول متوسط دنباله تا هشدار پس از ایجاد شیفت

انتخاب `K`، `H` و `λ` باید با هدف موردنظر و هزینه‌های خطا انجام شود.
