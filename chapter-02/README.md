## ۱. خلاصه مبانی مدار خردایش و طبقه‌بندی

مدار خردایش یکی از مهم‌ترین بخش‌های مصرف‌کننده انرژی در کارخانه‌های تغلیظ است و عملکرد آن مستقیماً بر دانه‌بندی محصول، ظرفیت مدار، بازیابی و کیفیت خوراک مراحل بعدی اثر می‌گذارد.

مهم‌ترین مفاهیم این فصل عبارت‌اند از:

1. **موازنه مدار بسته و بار در گردش ($C$):**
   بار در گردش بالا می‌تواند ظرفیت مؤثر آسیاب و تجهیزات طبقه‌بندی را محدود کند، در حالی که بار در گردش پایین ممکن است نشان‌دهنده کاهش بار برگشتی و تغییر شرایط عملیاتی مدار باشد. حدود مشخصی مانند `150%` یا `250%` باید متناسب با طراحی و شرایط واقعی هر مدار تفسیر شوند و یک معیار عمومی برای تمام کارخانه‌ها نیستند.

2. **شاخص کارایی باند ($\eta$):**

   $$\eta = \frac{W_{i,op}}{W_{i,lab}}$$

   این نسبت برای مقایسه شاخص کار عملیاتی با مقدار مرجع آزمایشگاهی استفاده می‌شود. افزایش آن می‌تواند نشان‌دهنده کاهش کارایی انرژی مدار باشد؛ با این حال، محدوده‌های مرجع باید بر اساس نوع سنگ، طراحی آسیاب، روش آزمون و شرایط عملیاتی تعیین شوند.

3. **هیدروسیکلون و منحنی ترومپ:**
   عملکرد طبقه‌بندی را می‌توان با منحنی ترومپ توصیف کرد. در این تحلیل، پارامترهایی مانند نرخ بای‌پس آب ($R_f$)، نقطه برش تصحیح‌شده ($d_{50c}$) و شاخص تیزی جدایش برای ارزیابی عملکرد سیکلون مورد استفاده قرار می‌گیرند.

4. **پدیده Roping:**
   در شرایط Roping، الگوی تخلیه ته‌ریز هیدروسیکلون از حالت عادی خارج شده و جریان ته‌ریز به شکل طنابی و متراکم‌تر ظاهر می‌شود. این وضعیت می‌تواند با افزایش عبور ذرات درشت به سرریز و اختلال در عملکرد طبقه‌بندی همراه باشد و در صورت تداوم، بر مراحل بعدی فرآیند اثر بگذارد.

## ۲. کارگاه‌های عملی چهارگانه با داده‌های صنعتی

### 📊 ۲.۱. کارگاه اکسل (Excel Hands-on: Tromp Curve)

**هدف:** رسم منحنی تفکیک هیدروسیکلون و استخراج نقطه برش تصحیح‌شده ($d_{50c}$).

#### مراحل

1. به شیت `Ch02_Cyclone_PSD_Tromp` بروید.

2. رابطه تفکیک ظاهری را بررسی کنید:

   $$T_i =\frac{C \times U_i}{(1+C)\times CF_i}\times 100$$

   و رابطه تفکیک تصحیح‌شده را به‌صورت زیر محاسبه کنید:

   $$T_{ci}=\max\left(0,\frac{T_i-R_f}{100-R_f}\times100\right)$$

   که در آن:

   * $T_i$: احتمال یا درصد تفکیک ظاهری ذرات در کلاس اندازه $i$
   * $T_{ci}$: احتمال تفکیک تصحیح‌شده
   * $R_f$: سهم بای‌پس آب
   * $C$: پارامتر مربوط به بار در گردش
   * $U_i$: جریان جرمی کلاس اندازه $i$ در ته‌ریز
   * $CF_i$: جریان جرمی کلاس اندازه $i$ در خوراک سیکلون

3. ستون اندازه ذرات را روی محور افقی قرار دهید و مقیاس محور افقی را **Logarithmic** انتخاب کنید.

4. ستون $T_{ci}$ را روی محور عمودی قرار دهید.

5. یک نمودار **Scatter with Smooth Lines** ایجاد کنید.

6. نقطه‌ای از منحنی را که در آن:

   $$T_{ci}=50\%$$

   قرار دارد، تعیین کنید.

7. اندازه ذرات متناظر با این نقطه به‌عنوان **نقطه برش تصحیح‌شده** یا $d_{50c}$ گزارش می‌شود.

> **نکته:** برای استخراج دقیق‌تر $d_{50c}$ بهتر است از درون‌یابی بین دو نقطه مجاور 50 درصد استفاده شود، به‌خصوص زمانی که داده‌های اندازه ذرات گسسته باشند.

### 📈 ۲.۲. کارگاه مینی‌تب (Minitab SPC: I-MR Chart)

**هدف:** پایش دانه‌بندی سرریز ($P_{80}$)، فشار هیدروسیکلون و شناسایی الگوهای بالقوه خارج از کنترل آماری.

#### مراحل در Minitab

1. داده‌های شیت `Ch02_Shift_KPI_Monitoring_SPC` را در Minitab وارد کنید.

2. از مسیر زیر استفاده کنید:

**Stat → Control Charts → Variables Charts for Individuals → I-MR**

3. متغیر `Cluster_Pressure_kPa` را انتخاب کنید.

4. در بخش **I-MR Options → Tests** آزمون‌های موردنظر را فعال کنید. در صورت استفاده از مجموعه هشت آزمون متداول Minitab، موارد زیر از مهم‌ترین آزمون‌ها هستند:

   * **Test 1:** یک نقطه خارج از محدوده $3\sigma$
   * **Test 2:** نه نقطه متوالی در یک سمت خط مرکزی

5. نمودار **Individuals (I)** و **Moving Range (MR)** را بررسی کنید.

6. نقاط خارج از حدود کنترل و الگوهای غیرتصادفی را با زمان شیفت و سایر KPIهای فرآیندی مقایسه کنید.

#### تفسیر مهندسی

مشاهده افزایش ناگهانی فشار، تغییر $P_{80}$ یا خروج نقاط از حدود کنترل می‌تواند یک **سیگنال هشدار فرآیندی** باشد.

در نمونه‌هایی که الگوی تخلیه ته‌ریز به‌عنوان `Roping` ثبت شده است، می‌توان بررسی کرد که آیا تغییرات معناداری در فشار، دانه‌بندی یا سایر متغیرهای فرآیندی هم‌زمان رخ داده است.

> **نکته مهم:** خروج یک متغیر از حدود کنترل به‌تنهایی اثبات‌کننده وقوع Roping نیست. تشخیص Roping باید با شواهد فرآیندی، الگوی تخلیه ته‌ریز و سایر شاخص‌های عملیاتی تأیید شود.

### 🐍 ۲.۳. کارگاه پایتون (Python: Grinding Energy & Efficiency Model)

**هدف:** تحلیل رابطه بین درصد جامد خروجی آسیاب، شاخص کارایی باند و انرژی ویژه مصرفی.

#### کد پایتون

```python
pip install pandas matplotlib numpy openpyxl

import os
import matplotlib.pyplot as plt
import numpy as np
import pandas as pd
# 1. بارگذاری داده‌های آسیاب
excel_path = "/home/qc/Data_Ch01_Ch02.xlsx"  # یا مسیر دلخواهت

df_energy = pd.read_excel(excel_path, sheet_name="Ch02_Grinding_Mill_Energy")

# 2. نام ستون‌های دقیق مطابق شیت اکسل
col_solids = "Mill_Discharge_Cw_pct"  # درصد جامد خروجی آسیاب
col_eta = "Bond_Efficiency_Eta"  # شاخص کارایی باند (Wi_op / Wi_lab)
col_espec = "E_spec_Plant_kWh_t"  # انرژی ویژه مصرفی (kWh/t)

# اعتبارسنجی ستون‌ها
required_columns = [col_solids, col_eta, col_espec]
missing = [c for c in required_columns if c not in df_energy.columns]
if missing:
    raise ValueError(f"ستون‌های یافت‌نشده در اکسل: {missing}")

# 3. ترسیم نمودار اسکتر سه‌متغیره
plt.figure(figsize=(9, 5), dpi=120)

scatter = plt.scatter(
    df_energy[col_solids],
    df_energy[col_eta],
    c=df_energy[col_espec],
    cmap="plasma",  # تم plasma یا viridis تفکیک رنگی عالی برای انرژی میده
    edgecolor="k",
    linewidth=0.5,
    alpha=0.85,
    s=55,
)

# 4. خط مرجع کارایی باند
plt.axhline(
    y=1.25,
    color="crimson",
    linestyle="--",
    linewidth=1.5,
    label="Reference Limit ($\eta = 1.25$)",
)

# 5. نوار رنگی و برچسب‌ها
cbar = plt.colorbar(scatter)
cbar.set_label("Specific Energy, $E_{spec}$ (kWh/t)", fontsize=10)

plt.xlabel("Mill Discharge Solids, $C_w$ (%)", fontsize=11, fontweight="bold")
plt.ylabel(
    r"Bond Efficiency, $\eta$ ($W_{i,op} / W_{i,lab}$)",
    fontsize=11,
    fontweight="bold",
)
plt.title(
    "Grinding Efficiency vs. Mill Slurry Solids Content",
    fontsize=12,
    fontweight="bold",
)

plt.grid(True, linestyle=":", alpha=0.6)
plt.legend(frameon=True, loc="upper right")
plt.tight_layout()

# ذخیره خروجی
os.makedirs("outputs", exist_ok=True)
plt.savefig("outputs/ch02_energy_efficiency.png", dpi=300, bbox_inches="tight")
plt.show()

```

#### تحلیل خروجی

نمودار امکان بررسی هم‌زمان سه متغیر را فراهم می‌کند:

* **محور افقی:** درصد جامد خروجی آسیاب
* **محور عمودی:** شاخص کارایی باند ($\eta$)
* **رنگ نقاط:** انرژی ویژه مصرفی، برحسب `kWh/t`

از این نمودار می‌توان برای شناسایی نواحی عملیاتی نامطلوب، بررسی روندهای احتمالی و انتخاب نقاطی برای تحلیل دقیق‌تر استفاده کرد.

> **نکته:** خط مرجع $\eta=1.25$ صرفاً یک مقدار نمونه برای تحلیل آموزشی است و نباید بدون اعتبارسنجی با داده‌های کارخانه به‌عنوان حد کنترلی قطعی فرآیند در نظر گرفته شود.

### 📉 ۲.۴. کارگاه پاور بی‌آی (Power BI: Plant Status Dashboard)

**هدف:** طراحی داشبورد پایش وضعیت مدار خردایش و طبقه‌بندی و ایجاد چراغ‌های هشدار برای شرایط بالقوه نامطلوب، از جمله Roping.

#### مراحل

1. داده‌های شیت زیر را در Power BI بارگذاری کنید:

```text
Ch02_Shift_KPI_Monitoring_SPC
```

2. ستون محاسباتی زیر را برای تعیین سطح هشدار سیکلون ایجاد کنید:

```DAX
Cyclone_Risk_Level =
SWITCH(
    TRUE(),
    'Ch02_Shift_KPI_Monitoring_SPC'[Underflow_Discharge_Pattern] = "Roping",
        "Critical",
    'Ch02_Shift_KPI_Monitoring_SPC'[Cluster_Pressure_kPa] > 130,
        "Warning",
    "Normal"
)
```

#### منطق سطح هشدار

| سطح        | شرط                           | تفسیر                           |
| ---------- | ----------------------------- | ------------------------------- |
| `Critical` | الگوی تخلیه ته‌ریز = `Roping` | نیازمند بررسی فوری وضعیت سیکلون |
| `Warning`  | فشار سیکلون > 130 kPa         | شرایط نیازمند بررسی             |
| `Normal`   | سایر شرایط                    | بدون هشدار تعریف‌شده            |

> **نکته:** مقدار `130 kPa` در این مثال یک حد آموزشی است. حدود هشدار واقعی باید بر اساس طراحی سیکلون، فشار نامی، نوع خوراک، درصد جامد، دانه‌بندی و سوابق عملیاتی کارخانه تعیین و اعتبارسنجی شود.

3. یک ویژوال **Matrix** ایجاد کنید و متغیرهای زیر را در آن قرار دهید:

   * شیفت
   * فشار سیکلون
   * $P_{80}$
   * الگوی تخلیه ته‌ریز
   * `Cyclone_Risk_Level`

4. برای ستون `Cyclone_Risk_Level` از **Conditional Formatting** استفاده کنید:

   * `Critical` → قرمز
   * `Warning` → زرد
   * `Normal` → سبز

5. در داشبورد، امکان فیلتر بر اساس **تاریخ، شیفت و وضعیت سیکلون** را اضافه کنید تا اپراتور یا کارشناس فرآیند بتواند وضعیت مدار را در بازه زمانی موردنظر بررسی کند.
