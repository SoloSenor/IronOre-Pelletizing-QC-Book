# فصل ۱۲: تحلیل علل ریشه‌ای چندمتغیره با PCA و SHAP

جعبه‌ابزار آموزشی توضیح‌پذیری مدل‌ها برای متالورژیست‌ها و مهندسان کنترل کیفیت صنایع کنسانتره و گندله‌سازی.

## محتویات بسته
- `data/ch12_pca_shap_dataset.xlsx`: دیتاست آموزشی پیوست‌شده؛ شیت `data`.
- `Chapter_12_Theory_and_Practice.md`: مبانی PCA، شاخص‌های T² و Q/SPE، و SHAP.
- `guides/python_guide.md`: راهنمای اجرای تحلیل پایتون.
- `guides/minitab_guide.md`: راهنمای تحلیل PCA در Minitab.
- `guides/powerbi_guide.md`: نکات داشبوردسازی Power BI.
- `guides/excel_guide.md`: راهنمای استانداردسازی و ماتریسی در Excel.
- `scripts/run_pca_shap_analysis.py`: اسکریپت تحلیل.

## شروع سریع
نصب وابستگی‌ها: `pip install pandas numpy scikit-learn xgboost shap matplotlib openpyxl`
از ریشه این پوشه اجرا کنید: `python scripts/run_pca_shap_analysis.py`
