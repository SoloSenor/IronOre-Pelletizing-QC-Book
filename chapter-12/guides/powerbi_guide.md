# راهنمای Power BI

از `Get Data > Excel workbook` فایل داده را بارگذاری کنید. برای داشبورد، کارت CCS، نرخ عدم انطباق، نمودار روند و scatter اسکورهای PCA قابل استفاده‌اند؛ نام ستون‌ها را با شیت `data` تطبیق دهید.

در صورت ساخت Python visual، فیلدها به‌عنوان `dataset` در دسترس‌اند. برای SHAP، مدل را در Python آموزش دهید و از داده‌ی انتخاب‌شده در ویژوال استفاده کنید. توجه: فیلتر شدن داده‌ها و بازآموزی مدل در هر تعامل ممکن است نتایج را ناپایدار کند؛ در استقرار، مدل ثابت و اعتبارسنجی‌شده را ترجیح دهید. آستانه T²/Q باید از مرجع فرایندی تعیین شود.
