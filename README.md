# 🚀 راهنمای جامع کنترل کیفیت داده‌محور (QC Data-Driven)
## از کنسانتره تا گندله‌سازی؛ جایی که متالورژی با علم‌داده ملاقات می‌کند!

به مخزنِ دانش و تجربه‌ی من خوش آمدید! این پروژه تلاشی است برای پل زدن بین دنیای سنتیِ **کنترل کیفیت (QC)** در صنایع معدنی و دنیای مدرنِ **تحلیل داده (Data Science)**.

اگر شما هم در خط مقدمِ تولید (کارخانه گندله‌سازی) هستید و از دیدن نوساناتِ کیفیِ بی‌دلیل خسته شده‌اید، یا می‌خواهید فراتر از اکسل‌های معمولی بروید، جای درستی آمده‌اید.

---

### 🛠 ابزارهای مورد استفاده در این مسیر
این کتاب فقط تئوری نیست؛ یک راهنمای عملیاتی است که برای اجرای آن از ترکیب قدرتِ ابزارهای زیر استفاده کرده‌ایم:

| ابزار | کاربرد |
| :--- | :--- |
| **Python** | تحلیل‌های پیشرفته، یادگیری ماشین و اتوماسیون |
| **Excel** | پایش روزانه و محاسبات سریع کیفی |
| **Minitab** | تحلیل‌های آماری دقیق و نمودارهای SPC |
| **Power BI** | داشبوردسازی و مانیتورینگ آنلاین کیفیت |

در این مستندات، فرآیند را از جدایش مغناطیسی تا کنترل نهایی گندله پوشش داده‌ایم:

*   **[فصل ۳: فرآوری مواد معدنی](#)** - جدایش مغناطیسی، فلوتاسیون، تیکنر و تحلیل‌های کیفی.
*   **[فصل ۵: کنترل کیفیت گندله‌سازی](#)** - پایش فرآیند پخت و مشخصات گندله سبز.

### 💡 درباره این پروژه
من این کتاب را نوشتم چون معتقدم در صنعتِ سنگ آهن، **داده‌ها طلا هستند**، اگر بدانیم چطور استخراجشان کنیم. هدفِ این پروژه این است که:
1. مهندسانِ QC را به ابزارهای تحلیلِ مدرن مجهز کند.
2. فرآیندهای تولید را شفاف، دقیق و پیش‌بینی‌پذیر کند.
3. تجربه‌ی عملیِ سال‌ها کار در صنعت را با فرمول‌های علمی ترکیب کند.
