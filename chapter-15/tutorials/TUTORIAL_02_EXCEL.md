# آموزش اکسل: تحلیل و کنترل کیفیت (فصل ۱۵)

در این آموزش، نحوه پیاده‌سازی نمودارهای کنترل کیفیت و محاسبات کلیدی در محیط اکسل تشریح شده است.

## سرفصل‌های آموزشی
1. **نمودارهای کنترل آماری (SPC)**:
   استفاده از فرمول‌های `AVERAGE` و `STDEV` برای محاسبه حدود کنترل (UCL/LCL).
2. **شبیه‌سازی EWMA**:
   پیاده‌سازی فرمول بازگشتی $Z_t = \lambda X_t + (1-\lambda)Z_{t-1}$ برای پایش تغییرات تدریجی میانگین.
3. **اعتبارسنجی داده**:
   استفاده از `Data Validation` و `Conditional Formatting` برای شناسایی داده‌های خارج از محدوده (Range Check).
