## ۱. مقدمه مهندسی و متالورژیکی

در فرآیند پخت گندله روی دستگاه **پالت‌کار (Traveling Grate)**، بستر گندله خام به همراه لایه محافظ کف و دیواره‌ها (**Hearth Layer**) یک بستر آکنده متخلخل (**Packed Bed**) را تشکیل می‌دهد.

عبور گازهای داغ فرآیندی از میان منافذ این بستر موجب ایجاد افت فشار هیدرولیکی (`Delta P`) می‌شود.

برای توصیف این پدیده می‌توان از **معادله ارگون (Ergun Equation)** استفاده کرد. این رابطه یک مدل نیمه‌تجربی شناخته‌شده برای توصیف افت فشار جریان سیال در بسترهای آکنده است و از دو مؤلفه اصلی تشکیل می‌شود:

1. **مؤلفه ویسکوز (Viscous Term)** که اثرات اصطکاکی و لزجتی جریان را توصیف می‌کند.
2. **مؤلفه اینرسی (Inertial Term)** که اثرات اینرسی سیال و افزایش غیرخطی افت فشار با سرعت را توصیف می‌کند.

بنابراین، ضرایب رابطه نباید صرفاً با یک رگرسیون آماری دلخواه، مانند `LINEST`، تعیین شوند؛ بلکه ساختار معادله و پارامترهای فیزیکی آن باید بر اساس ویژگی‌های بستر، ذرات و گاز فرآیندی تعریف شوند.

### معادله ارگون

رابطه افت فشار در واحد طول بستر به‌صورت زیر است:

```text
Delta P / L =
[150 * mu_g * (1 - eps)^2 / (phi^2 * dp^2 * eps^3)] * vs
+
[1.75 * rho_g * (1 - eps) / (phi * dp * eps^3)] * vs^2
```

پارامترهای اصلی عبارت‌اند از:

| نماد      | پارامتر           | واحد     |
| --------- | ----------------- | -------- |
| `Delta P` | افت فشار کل بستر  | Pa       |
| `L`       | ضخامت بستر        | m        |
| `mu_g`    | لزجت دینامیکی گاز | Pa.s     |
| `rho_g`   | چگالی گاز         | kg/m3    |
| `eps`     | تخلخل بستر        | بدون بعد |
| `phi`     | ضریب کرویت ذرات   | بدون بعد |
| `dp`      | قطر معادل ذرات    | m        |
| `vs`      | سرعت سطحی گاز     | m/s      |

در این کارگاه ابتدا مدل هیدرودینامیکی ارگون در Excel پیاده‌سازی می‌شود. سپس حساسیت افت فشار نسبت به **سرعت سطحی گاز** و **تخلخل بستر** بررسی شده و در ادامه داده‌های ساعتی کارخانه برای پایش زون‌های حرارتی و افت فشار تحلیل می‌شوند.

# گام ۱ — پیکربندی متغیرهای سلولی در شیت `Ergun_Equation_Lab`

در شیت `Ergun_Equation_Lab` یک پنل برای پارامترهای ورودی ایجاد کنید.

برای افزایش خوانایی و قابلیت ردیابی فرمول‌ها، برای سلول‌های مربوط به پارامترهای فیزیکی از **Defined Name** استفاده کنید.

مسیر ایجاد نام:

**Formulas → Define Name**

پارامترهای پیشنهادی:

| Defined Name | پارامتر فیزیکی      |  واحد | مقدار مبنا | توضیح                             |
| ------------ | ------------------- | ----: | ---------: | --------------------------------- |
| `mu_g`       | لزجت دینامیکی گاز   |  Pa.s |  `4.5E-05` | مقدار نمونه برای گاز داغ فرآیندی  |
| `rho_g`      | چگالی مؤثر گاز داغ  | kg/m3 |     `0.90` | مقدار نمونه در شرایط فرآیندی      |
| `eps`        | تخلخل ظاهری بستر    |     - |     `0.40` | نسبت حجم فضای خالی به حجم کل بستر |
| `phi`        | ضریب کرویت گندله    |     - |     `0.85` | ضریب شکل تقریبی گندله             |
| `dp`         | قطر معادل ذرات      |     m |   `0.0125` | معادل 12.5 mm                     |
| `vs`         | سرعت سطحی ظاهری گاز |   m/s |     `1.80` | سرعت گاز بر مبنای سطح مقطع بستر   |
| `L`          | ضخامت مؤثر بستر     |     m |     `0.35` | معادل 350 mm                      |

> **نکته مهندسی:** مقادیر فوق نمونه هستند. برای استفاده صنعتی باید پارامترهای `mu_g`، `rho_g`، `dp`، `eps` و `phi` بر اساس شرایط واقعی فرآیند، روش اندازه‌گیری و طراحی تجهیزات تعیین یا اعتبارسنجی شوند.

# گام ۲ — پیاده‌سازی معادله ارگون و جدول حساسیت دوورودی

## ۲-۱. محاسبه افت فشار کل

در سلول محاسبه افت فشار، فرمول زیر را وارد کنید:

```excel
=((150*mu_g*(1-eps)^2)/(phi^2*dp^2*eps^3)*vs+(1.75*rho_g*(1-eps))/(phi*dp*eps^3)*vs^2)*L/1000
```

خروجی این فرمول بر حسب `kPa` خواهد بود.

### تفکیک مؤلفه ویسکوز

برای محاسبه سهم مؤلفه ویسکوز:

```excel
=((150*mu_g*(1-eps)^2)/(phi^2*dp^2*eps^3)*vs)*L/1000
```

### تفکیک مؤلفه اینرسی

برای محاسبه سهم مؤلفه اینرسی:

```excel
=((1.75*rho_g*(1-eps))/(phi*dp*eps^3)*vs^2)*L/1000
```

### کنترل صحت محاسبات

باید رابطه زیر برقرار باشد:

```text
Delta P Total = Delta P Viscous + Delta P Inertial
```

برای کنترل این موضوع، یک سلول جداگانه ایجاد کنید:

```excel
=Cell_Total_DP-(Cell_Viscous_DP+Cell_Inertial_DP)
```

در صورت صحت محاسبات، مقدار این سلول باید صفر یا بسیار نزدیک به صفر باشد.

# گام ۳-۱ — محاسبه میانگین متحرک ۲۴ ساعته دمای پخت

برای کاهش اثر نوسانات کوتاه‌مدت سنسور و مشاهده روند حرارتی پایدارتر، ستونی با نام زیر ایجاد کنید:

```text
Temp_Firing_MA24
```

در اولین سلول داده این ستون، فرمول زیر را وارد کنید:

```excel
=AVERAGE(OFFSET([@Temp_Firing_C],-MIN(ROW([@Temp_Firing_C])-ROW(tbl_Process[#Headers])-1,23),0,MIN(ROW([@Temp_Firing_C])-ROW(tbl_Process[#Headers]),24),1))
```

این فرمول از ابتدای جدول به‌صورت تطبیقی عمل می‌کند و:

* در رکوردهای ابتدایی، میانگین داده‌های موجود را محاسبه می‌کند.
* پس از تکمیل ۲۴ رکورد، میانگین متحرک ۲۴ ساعته را محاسبه می‌کند.
* با حرکت در جدول، پنجره محاسباتی به‌صورت خودکار جابه‌جا می‌شود.

> **نکته:** قبل از محاسبه Rolling Average، داده‌ها باید بر اساس Timestamp به‌ترتیب زمانی صعودی مرتب شده باشند.

# گام ۳-۲ — استخراج Target زون با `XLOOKUP`

در جدول ارزیابی عملکرد زون‌ها، می‌توان حدود پایین و بالای دمای هر زون را از جدول `tbl_Zones` استخراج کرد.

فرمول محاسبه انحراف دمای واقعی از Target Midpoint:

```excel
=LET(zone_name,[@Zone],t_min,XLOOKUP(zone_name,tbl_Zones[Zone_Name],tbl_Zones[Target_Temp_Min_C],0),t_max,XLOOKUP(zone_name,tbl_Zones[Zone_Name],tbl_Zones[Target_Temp_Max_C],0),t_target,(t_min+t_max)/2,[@Temp_Avg]-t_target)
```

خروجی این فرمول مقدار انحراف دمای واقعی از نقطه میانی پنجره هدف را نشان می‌دهد.

### تفسیر خروجی

```text
Deviation = 0
```

دمای واقعی برابر با Target Midpoint است.

```text
Deviation > 0
```

دمای واقعی بالاتر از Target Midpoint است.

```text
Deviation < 0
```

دمای واقعی پایین‌تر از Target Midpoint است.

## نکات اعتبارسنجی نهایی

پیش از استفاده از این مدل برای تصمیم‌گیری صنعتی، موارد زیر باید بررسی شوند:

1. اعتبار پارامترهای `mu_g` و `rho_g` در دما و فشار واقعی گاز.
2. روش تعیین قطر معادل `dp`.
3. روش تعیین تخلخل واقعی بستر `eps`.
4. اعتبار ضریب کرویت `phi` برای گندله موردنظر.
5. انطباق ضخامت بستر `L` با شرایط واقعی پالت‌کار.
6. اعتبار آستانه `4.5 kPa` برای Windbox.
7. اعتبار بازه دمایی `1250–1330 °C` برای فرآیند واقعی.
8. مقایسه `Delta P` پیش‌بینی‌شده با داده‌های واقعی کارخانه.
9. بررسی اثر رطوبت، دانه‌بندی، تخلخل و توزیع اندازه گندله بر مقاومت بستر.
10. اعتبارسنجی قواعد هشدار با داده تاریخی و نظر متخصص فرآیند.

> **اصل مهم:** این مدل باید به‌عنوان یک ابزار **تحلیل و پایش مهندسی** استفاده شود و جایگزین اندازه‌گیری واقعی، طراحی تجهیزات یا حدود عملیاتی تأییدشده کارخانه نیست.
