پایگاه داده استفاده‌شده: [`Chapter08_Pellet_Nonnormal_Capability_Dataset.xlsx`](../data/Chapter08_Pellet_Nonnormal_Capability_Dataset.xlsx)

### ۱. آمار توصیفی و آزمون‌های اولیه
برای تحلیل ستون CCS گندله‌ها (شیت `chapter8_ccs_100`، سلول‌های `A2:A101`):

| شاخص آماری | فرمول اکسل | تفسیر مهندسی در گندله‌سازی |
| :--- | :--- | :--- |
| **تعداد نمونه (n)** | `=COUNT(A2:A101)` | اندازه نمونه معتبر جهت سنجش پایداری تخمین دم‌ها |
| **میانگین** | `=AVERAGE(A2:A101)` | موقعیت مرکزی مقاومت فشاری سرد (CCS) |
| **انحراف معیار نمونه (s)** | `=STDEV.S(A2:A101)` | پراکندگی کل گندله‌های تست‌شده |
| **میانه (M)** | `=MEDIAN(A2:A101)` | نقطه تمرکز ۵۰٪ داده‌ها (مقاوم در برابر داده‌های پرت) |
| **چولگی (Skewness)** | `=SKEW(A2:A101)` | عدم تقارن؛ مقادیر مثبت (>0.5) نشان‌دهنده چولگی به راست است |
| **کشیدگی (Kurtosis)** | `=KURT(A2:A101)` | **دقت:** این تابع *Excess Kurtosis* را محاسبه می‌کند. برای کشیدگی استاندارد ۳ واحد اضافه کنید. |

### ۲. محاسبه شاخص Cpl در فرض کلاسیک نرمال و نمایش خطا
با توجه به اینکه استاندارد CCS فقط حد پذیرش پایینی (LSL = 250 kg) دارد:

* **شاخص Cpl نرمال:**
  ```excel
  =(AVERAGE(A2:A101) - 250) / (3 * STDEV.S(A2:A101))
  ```
  *(نتیجه: حدود ۰٫۴۲۹)*

* **درصد شکست فرضی با مدل نرمال:**
  ```excel
  =NORM.DIST(250, AVERAGE(A2:A101), STDEV.S(A2:A101), TRUE)
  ```
  *(نتیجه فرضی: حدود ۹٫۹٪ عدم انطباق)*

* **درصد نامنطبق واقعی مشاهده‌شده:**
  ```excel
  =COUNTIF(A2:A101, "<250") / COUNT(A2:A101)
  ```
  *(نتیجه واقعی: دقیقاً ۵٫۰٪)*

> **درس کلیدی مهندسی:** فرض کورکورانه توزیع نرمال بر روی داده چوله، نرخ گندله‌های زیر حد مجاز را تا ۲ برابر بدبینانه‌تر برآورد می‌کند!

### ۳. تقریب صدکی کلمنتس (Clements) در اکسل و محدودیت آن
برای صدک P0.135% و P99.865%:
* **حد پایین معادل تجربی:**
  ```excel
  =PERCENTILE.INC(A2:A101, 0.00135)
  ```
* **شاخص Cpl صدکی تجربی:**
  ```excel
  =(MEDIAN(A2:A101) - 250) / (MEDIAN(A2:A101) - PERCENTILE.INC(A2:A101, 0.00135))
  ```

⚠️ **هشدار متدولوژی کتاب:** با n=100، ضرب 100 × 0.00135 = 0.135 است؛ یعنی این صدک زیر اولین دیتای نمونه قرار می‌گیرد و برآورد تجربی آن ناپایدار است. برای تحلیل رسمی صنعتی، برازش توزیع پیرسون یا تبدیل ترجیح داده می‌شود.

### ۴. تبدیل باکس-کاکس (Box-Cox) در اکسل
اگر λ ≠ 0:

Y = (X^λ − 1) / λ

در شیت `capability_calc` اکسل با λ = −1.020، تبدیل داده‌ها و تبدیل متناظر LSL:
```excel
=(250^(-1.020) - 1) / (-1.020)
```
سپس محاسبه Cpl در فضای نرمال‌شده جدید:
```excel
=(AVERAGE(Y_range) - LSL_Y) / (3 * STDEV.S(Y_range))
```
