# راهنمای پیاده‌سازی کنترل کیفیت فصل ۳ در Microsoft Excel

این سند مراحل پیاده‌سازی محاسبات موازنه، اعتبارسنجی داده و نمودارهای کنترل کیفیت را بر روی فایل [`Chapter03_QC_Separation_Dewatering_Data.xlsx`](../datasets/Chapter03_QC_Separation_Dewatering_Data.xlsx) تشریح می‌کند.

---

## ۱. فرمول‌های کلیدی در Excel

در شیت `Process_Data`، فرمول‌های زیر را برای ردیف ۲ وارد کرده و به کل ستون تعمیم دهید.

### دبی خشک خوراک

```excel
=G2*(H2/100)
```

> `G2 = Feed_Wet_tph`
> `H2 = Feed_Solids_pct`

### بازده جرمی کنسانتره

```excel
=(AI2/AH2)*100
```

> `AI2 = Concentrate_Dry_tph`
> `AH2 = Feed_Dry_tph`

### بازیابی آهن

```excel
=(AI2*AK2)/(AH2*J2)*100
```

> `AI2 = Concentrate_Dry_tph`
> `AK2 = Concentrate_Fe_pct`
> `AH2 = Feed_Dry_tph`
> `J2 = Feed_Fe_pct`

### خطای موازنه آهن

```excel
=((AH2*J2)-(AI2*AK2+AJ2*AM2))/(AH2*J2)*100
```

> `AJ2 = Tailings_Dry_tph`
> `AM2 = Tailings_Fe_pct`

## ۲. اعتبارسنجی داده با Conditional Formatting

برای شناسایی سریع شرایط غیرعادی:

### رطوبت کیک

ستون `Filter_Cake_Moisture_pct` را انتخاب کنید و شرط زیر را اعمال کنید:

```text
Cell Value > 10.5
```

این شرط در این Dataset یک **حد آموزشی نمونه** است.

### کدورت سرریز تیکنر

برای ستون `Thickener_Overflow_Turbidity_NTU`:

```text
Cell Value > 50
```

این مقدار نیز باید برای کاربرد صنعتی با طراحی تیکنر و کیفیت مورد انتظار آب سرریز اعتبارسنجی شود.

### انحراف موازنه آهن

برای ستون `Fe_Balance_Error_pct` از Formula Rule زیر استفاده کنید:

```excel
=ABS(AQ2)>5
```

این شرط نقاطی را مشخص می‌کند که خطای مطلق موازنه آهن آن‌ها بیش از ۵٪ است.

> عبور از این آستانه الزاماً به معنی خرابی تجهیزات نیست و می‌تواند ناشی از نمونه‌برداری، زمان‌بندی نامناسب نمونه‌ها، خطای آزمایشگاهی، رطوبت، ابزار دقیق یا ناپایداری واقعی فرآیند باشد.

## ۳. رسم Run Chart برای رطوبت کیک

1. ستون `DateTime` را انتخاب کنید.
2. ستون `Filter_Cake_Moisture_pct` را به‌عنوان محور مقدار اضافه کنید.
3. از مسیر **Insert → Line Chart** نمودار را ایجاد کنید.
4. سه خط مرجع اضافه کنید:

* `USL = 10.5%`
* `Target = 9.5%`
* `LSL = 8.5%`

این خطوط **حدود مشخصات آموزشی Dataset** هستند و با حدود کنترل آماری یکسان نیستند.

### نکته مهم

**Specification Limits** مانند USL و LSL با **Control Limits** مانند UCL و LCL تفاوت دارند.

حدود مشخصات توسط نیاز محصول یا فرآیند تعیین می‌شوند؛ حدود کنترل از رفتار آماری فرآیند استخراج می‌شوند.

## ۴. تفسیر QC

اگر رطوبت کیک از USL عبور کند، بررسی علل احتمالی باید از زنجیره زیر آغاز شود:

**Feed Solids → Slimes → Thickener Underflow → Vacuum → Filter Cloth → Cake Formation → Moisture**

به‌جای نسبت دادن مستقیم تغییر رطوبت به یک متغیر، ابتدا روند و هم‌زمانی تغییرات متغیرها بررسی شود.
