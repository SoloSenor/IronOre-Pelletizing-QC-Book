# مستندات و دیکشنری داده‌های فصل ۳

## مشخصات Dataset

* **نام فایل:** `Chapter03_QC_Separation_Dewatering_Data.xlsx`
* **تعداد رکورد:** ۳۶۰ رکورد
* **دوره:** ۳۰ روز
* **فرکانس نمونه‌برداری:** هر ۲ ساعت
* **نوع داده:** داده مصنوعی مهندسی‌شده
* **هدف:** آموزش کنترل کیفیت، موازنه جرمی، SPC، تحلیل آماری و داشبوردسازی

داده‌ها به‌صورت مصنوعی تولید شده‌اند، اما روابط و دامنه متغیرها با هدف ایجاد یک سناریوی آموزشی نزدیک به رفتار فرآیندهای جدایش، تیکنر و فیلتراسیون طراحی شده‌اند.

> این Dataset برای آموزش و توسعه روش تحلیل مناسب است و نباید به‌عنوان داده واقعی یک کارخانه یا مبنای تعیین حدود عملیاتی صنعتی استفاده شود.

## شیت‌های موجود

### ۱. `README`

راهنمای استفاده از Dataset و حدود نمونه مورد استفاده در آموزش.

### ۲. `Data_Dictionary`

تعریف متغیرها، واحد اندازه‌گیری، نوع داده و نقش فرآیندی هر ستون.

### ۳. `Process_Data`

جدول اصلی داده‌های فرآیندی شامل متغیرهای:

* خوراک
* جدایش مغناطیسی
* فلوتاسیون
* تیکنر
* فیلتراسیون
* عیار و بازیابی
* موازنه آهن

### ۴. `Calculations`

محاسبات مشتق‌شده شامل:

* Feed Dry tph
* Mass Yield
* Fe Recovery
* Fe Balance Error

### ۵. `SPC_Sample`

زیرمجموعه‌ای از داده‌ها برای تحلیل آماری و رسم نمودارهای کنترلی در Minitab.

### ۶. `Dashboard_Data`

داده‌های تجمیع‌شده روزانه برای استفاده در Power BI.

### ۷. `Minitab_Import`

جدول ساده‌شده و مناسب برای انتقال مستقیم داده‌ها به Minitab.

## منطق اصلی Dataset

ساختار داده به‌گونه‌ای طراحی شده است که بتوان ارتباط احتمالی زیر را بررسی کرد:

```text
Feed Characteristics
        ↓
Magnetic Separation / Flotation
        ↓
Grade & Recovery
        ↓
Thickener
        ↓
Filter
        ↓
Cake Moisture
```

و در کنار آن:

```text
Feed Slimes
      ↓
Thickener / Filtration Behavior
      ↓
Cake Moisture
```

## نکته مهم درباره داده‌های آموزشی

هر رابطه مشاهده‌شده در Dataset باید با توجه به ماهیت مصنوعی داده‌ها تفسیر شود.

به‌خصوص:

* همبستگی ≠ علیت
* Signal ≠ Root Cause
* Control Limit ≠ Specification Limit
* Capability ≠ Stability
* Statistical Significance ≠ Engineering Significance

هدف اصلی Dataset، آموزش **روش فکر کردن داده‌محور در QC** است، نه ارائه یک مدل عمومی برای همه کارخانه‌های کنسانتره سنگ‌آهن.
