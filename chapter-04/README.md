# فصل ۴: گندله‌سازی خام — مکانیک محیط‌های دانه‌ای، آزمون‌های تر و خشک و کنترل کیفیت داده‌محور

خوش آمدید!

این پوشه شامل مستندات نظری، دیتاست آموزشی شبیه‌سازی‌شده و راهنماهای تحلیل داده برای فصل چهارم کتاب **کنترل کیفیت داده‌محور در زنجیره فولاد** است.

تمرکز این فصل بر مرحله **گندله‌سازی خام (Green Pelletizing)** و ارتباط بین ویژگی‌های خوراک، رطوبت، بایندر، شرایط دیسک، دانه‌بندی و خواص مکانیکی گندله خام است.

> **نکته مهم:** داده‌ها و حدود عددی ارائه‌شده در این فصل آموزشی هستند و نباید به‌عنوان حدود عمومی یا specification ثابت برای همه کارخانه‌های گندله‌سازی تلقی شوند. حدود عملیاتی باید بر اساس خوراک، کانی‌شناسی، PSD، نوع و تنظیمات دیسک، نوع بایندر، شرایط آب و الزامات محصول هر کارخانه اعتبارسنجی شوند.

## 🎯 فلسفه تحلیل در این فصل

هدف فقط تعیین اینکه یک مقدار «خوب» یا «بد» است نیست.

زنجیره تحلیل باید تا حد امکان به شکل زیر دنبال شود:

**شرایط خوراک → PSD و ریزدانه‌ها → رطوبت و بایندر → شرایط دیسک → تشکیل گندله → استحکام و دانه‌بندی → اقدام اصلاحی**

همچنین باید بین مفاهیم زیر تمایز قائل شد:

* **Specification Limit** با **Control Limit**
* **Signal** با **Root Cause**
* **Correlation** با **Causation**
* **Capability** با **Stability**
* **Statistical Significance** با **Engineering Significance**

این تمایزها در تمام تحلیل‌های فصل رعایت می‌شوند.
