# گام ۱: پاکسازی داده و انتخاب رژیم پایدار

در مدل‌سازی پیش‌بین، داده‌های راه‌اندازی، Recovery و Disturbance می‌توانند رابطه بین متغیرهای ورودی و خروجی را مخدوش کنند.

در شیت `Shift_Data`:

1. Filter را فعال کنید.
2. ستون `Process_Stability` را پیدا کنید.
3. ابتدا داده‌های `Stable` را برای مدل پایه انتخاب کنید.
4. رکوردهای `Startup/Recovery` و `Process_Disturbance` را حذف نکنید؛ آنها را برای تحلیل جداگانه نگه دارید.
5. یک شیت جدید با نام `Stable_Data` ایجاد کنید.

> حذف داده‌های ناپایدار باید بر اساس تعریف عملیاتی رژیم فرایندی انجام شود، نه صرفاً برای افزایش شاخص‌های برازش مدل.

# گام ۲: مهندسی ویژگی‌های شیمیایی

فرض کنید:

* `D` = `SiO2`
* `E` = `Al2O3`
* `F` = `CaO`
* `G` = `MgO`

## 2.1 — شاخص Gangue

در یک ستون جدید:

```excel
=D2+E2
```

نام پیشنهادی ستون:

```text
Gangue_SiAl
```

تعریف:

$$
Gangue_{SiAl}=SiO_2+Al_2O_3
$$

این شاخص آموزشی است و نباید به‌عنوان تمام اجزای gangue در هر خوراک تلقی شود.

# گام ۶: مدل‌سازی ریسک دُم چپ

فرض کنید:

```text
Z2 = predicted CCS mean
AA2 = predicted CCS standard deviation
```

و برای این مثال آموزشی:

```text
LSL = 2000 N
```

است.

> `2000 N` در این مثال **حد مشخصات آموزشی** است و از ISO 4700 به‌عنوان LSL عمومی استخراج نشده است. ISO 4700 روش آزمون crushing strength را مشخص می‌کند.

احتمال زیر LSL:

```excel
=NORM.DIST(2000,Z2,AA2,TRUE)
```

یا با استفاده از سلول LSL:

```excel
=NORM.DIST($AB$1,Z2,AA2,TRUE)
```

که در آن `AB1` برابر LSL است.

# گام ۷: محاسبه P10 تحت فرض Normal

اگر:

```text
Z2 = μ
AA2 = σ
```

باشد:

```excel
=NORM.INV(0.10,Z2,AA2)
```

این مقدار برابر با:

$$
P10=\mu+z_{0.10}\sigma
$$

است.

> این محاسبه فقط در چارچوب فرض نرمال بودن توزیع شرطی CCS معتبر است. اگر توزیع دیگری انتخاب شود، P10 باید از همان توزیع محاسبه شود.

# گام ۸: کارت هشدار ریسک

اگر احتمال زیر LSL در `AC2` قرار دارد:

```excel
=IF(AC2>0.05,"نیازمند بررسی","در محدوده پایش")
```

عدد `5%` در اینجا یک **آستانه آموزشی** است و نباید به‌عنوان حد عمومی صنعتی استفاده شود.

در پروژه واقعی باید این آستانه با توجه به:

* Specification
* هزینه Failure
* هزینه Inspection
* نرخ False Alarm
* ظرفیت فرایند
* الزامات مشتری

کالیبره شود.

# گام ۹: کنترل منطقی مدل

قبل از استفاده عملی، موارد زیر بررسی شوند:

* `σ > 0`
* تعداد کافی آزمون CCS
* عدم وجود داده پرت ناشی از خطای آزمایش
* هم‌ترازی صحیح Lot و زمان
* عدم استفاده از متغیرهای پس از تولید به‌عنوان predictor
* بررسی residualها
* بررسی هم‌خطی بین predictors
* اعتبارسنجی روی داده خارج از نمونه آموزش
