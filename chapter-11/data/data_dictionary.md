# فرهنگ جامع متغیرهای دیتاست فصل ۱۱

این فایل تعریف متغیرهای مورد استفاده در فصل ۱۱ را ارائه می‌کند.

> **اصل مهم:** دامنه‌های عددی این جدول، در صورت وجود، دامنه آموزشی دیتاست هستند و نباید بدون اعتبارسنجی به‌عنوان Specification یا Operating Window عمومی صنعت تلقی شوند.

---

## 1. شناسه و متادیتا

| نام متغیر           | نام فارسی            |   واحد   | نقش     | توضیح                                                      |
| :------------------ | :------------------- | :------: | :------ | :--------------------------------------------------------- |
| `Lot_ID`            | شناسه لات/بچ         |     -    | شناسه   | کلید ارتباط داده‌های شیفت و آزمون‌های تک‌گندله             |
| `DateTime_End`      | زمان پایان لات/شیفت  | datetime | زمانی   | مبنای هم‌ترازی زمانی داده‌ها                               |
| `Shift`             | شیفت تولید           |     -    | متادیتا | شناسه شیفت تولید                                           |
| `Process_Stability` | وضعیت پایداری فرایند |     -    | متادیتا | مانند `Stable`، `Startup/Recovery` و `Process_Disturbance` |

# 3. ویژگی‌های ترکیبی

## 3.1 Gangue_SiAl

تعریف:

$$
Gangue_{SiAl}=SiO_2+Al_2O_3
$$

این شاخص فقط مجموع `SiO2` و `Al2O3` است و نباید بدون تعریف بیشتر به‌عنوان «کل gangue» تلقی شود.

| نام متغیر     | نام فارسی             | واحد | نقش                 |
| :------------ | :-------------------- | :--: | :------------------ |
| `Gangue_SiAl` | مجموع سیلیس و آلومینا |   %  | Feature Engineering |

---

## 3.2 Basicity_B2

تعریف:

$$
B_2=
\frac{CaO}{SiO_2}
$$

| نام متغیر     | نام فارسی       | واحد | نقش                 |
| :------------ | :-------------- | :--: | :------------------ |
| `Basicity_B2` | بازیسیته دوگانه |   -  | شاخص ترکیبی شیمیایی |

---

## 3.3 Basicity_B4

تعریف:

$$
B_4=
\frac{CaO+MgO}
{SiO_2+Al_2O_3}
$$

| نام متغیر     | نام فارسی         | واحد | نقش                 |
| :------------ | :---------------- | :--: | :------------------ |
| `Basicity_B4` | بازیسیته چهارگانه |   -  | شاخص ترکیبی شیمیایی |

> تعریف basicity باید مطابق قرارداد پروژه یا کارخانه حفظ شود؛ نام `B2` یا `B4` به‌تنهایی جایگزین تعریف ریاضی نیست.

# 4. متغیرهای حرارتی و کوره

| نام متغیر             | نام فارسی             |  واحد  | نقش                    |
| :-------------------- | :-------------------- | :----: | :--------------------- |
| `T_preheat_avg`       | میانگین دمای پیش‌گرم  |   °C   | ویژگی حرارتی           |
| `T_firing_avg`        | میانگین دمای پخت      |   °C   | ویژگی حرارتی           |
| `T_firing_peak`       | دمای اوج پخت          |   °C   | ویژگی حرارتی           |
| `TimeAbove1200_min`   | زمان بالاتر از 1200°C |   min  | زمان حرارتی            |
| `TimeAbove1250_min`   | زمان بالاتر از 1250°C |   min  | زمان حرارتی            |
| `HeatingRate_C_min`   | نرخ گرمایش            | °C/min | ویژگی دینامیکی         |
| `CoolingRate_C_min`   | نرخ سرمایش            | °C/min | ویژگی دینامیکی         |
| `Temp_Uniformity_Std` | انحراف معیار دمایی    |   °C   | شاخص یکنواختی حرارتی   |
| `O2_avg_pct`          | اکسیژن متوسط گاز      |    %   | شاخص شرایط اکسیدکنندگی |

`Temp_Uniformity_Std` می‌تواند به‌عنوان شاخصی از پراکندگی دمایی استفاده شود، اما تفسیر آن باید با محل سنسورها، نحوه نمونه‌برداری و ساختار واقعی بستر کوره هماهنگ باشد.

`O2_avg_pct` نیز به‌تنهایی تعیین‌کننده وضعیت متالورژیکی نیست و باید همراه با دما، زمان ماند، نفوذ گاز و سایر متغیرهای فرایندی تفسیر شود.

# 5. خروجی‌های CCS در سطح Lot

| نام متغیر  | نام فارسی            |   واحد   | نقش آماری     |
| :--------- | :------------------- | :------: | :------------ |
| `CCS_mean` | میانگین مقاومت فشاری | N/pellet | شاخص مرکزی    |
| `CCS_std`  | انحراف معیار CCS     |     N    | شاخص پراکندگی |
| `CCS_P10`  | صدک دهم CCS          |     N    | شاخص دُم چپ   |
| `n_CCS`    | تعداد آزمون‌های CCS  |   count  | حجم نمونه     |

### نکته

`CCS_std` و `CCS_P10` به تعداد نمونه‌های تک‌گندله‌ای و روش نمونه‌برداری حساس هستند. بنابراین مقایسه این شاخص‌ها بین Lotها بدون توجه به `n_CCS` می‌تواند گمراه‌کننده باشد.

# 7. BlackCore_frac

| نام متغیر        | نام فارسی                    | واحد | نقش              |
| :--------------- | :--------------------------- | :--: | :--------------- |
| `BlackCore_frac` | کسر گندله‌های دارای مغز سیاه |  0–1 | خروجی تجمیعی Lot |

این متغیر با `Has_BlackCore` یکسان نیست.

رابطه مفهومی:

$$
BlackCore\_frac
=
\frac{N_{BlackCore}}
{N_{Total}}
$$

اگر داده تک‌گندله‌ای کامل و نمونه‌برداری نماینده باشد.

# 9. Specification و Threshold

این متغیرها باید از یکدیگر تفکیک شوند:

| مفهوم            | مثال   | معنی                  |
| :--------------- | :----- | :-------------------- |
| `LSL`            | 2000 N | حد پایین مشخصات محصول |
| `Risk Threshold` | 5%     | آستانه تصمیم‌گیری مدل |
| `Control Limit`  | آماری  | حد کنترل فرایند       |

`LSL = 2000 N` در مثال‌های این فصل یک مقدار آموزشی است و نباید به‌عنوان حد عمومی ISO استفاده شود.

ISO 4700:2015 روش تعیین crushing strength گندله را مشخص می‌کند و در سال 2026 همچنان نسخه جاری اعلام شده است.

# 11. Time Lag

برای اتصال شرایط فرایندی به محصول:

```text
Process Time
      ↓
Residence Time / Transport Delay
      ↓
Product / Lot
```

باید در نظر گرفته شود.

متغیرهای فرایندی نباید صرفاً بر اساس نزدیک‌ترین timestamp به محصول متصل شوند، مگر اینکه این روش با زمان ماند واقعی خط سازگار باشد.

# 12. کنترل کیفیت داده

پیش از مدل‌سازی موارد زیر بررسی شوند:

* واحدها
* محدوده فیزیکی مقادیر
* Missing Values
* Duplicate `Lot_ID`
* تعداد آزمون‌های هر Lot
* زمان نمونه‌برداری
* تغییرات روش آزمایش
* Calibration تجهیزات
* Outlierهای آزمایشگاهی
* هم‌ترازی زمانی

# 13. اصل تفسیر

داده‌های این فصل برای ساخت رابطه زیر استفاده می‌شوند:

```text
Chemical State
      +
Thermal History
      +
Gas Conditions
      +
Process Stability
      ↓
CCS Distribution
      ↓
Tail Risk
      +
Black Core Risk
```

اما مدل آماری به‌تنهایی علت فیزیکی را اثبات نمی‌کند.

برای ادعای علت باید:

```text
Statistical Evidence
+
Process Evidence
+
Metallurgical Evidence
+
Physical Verification
```

همزمان بررسی شوند.
