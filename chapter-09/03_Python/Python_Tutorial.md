
## ۳. توضیحات اجزای فنی اسکریپت
* **کلاس RobustScaler:** به دلیل وجود پالس‌های نویز در سنسورهای فیلد (مانند دانسیته‌سنج رادیواکتیو یا دبی‌سنج مغناطیسی)، استفاده از `RobustScaler` به جای `StandardScaler` مانع از اثرگذاری داده‌های پرت بر میانگین ویژگی‌ها می‌شود.
* **جداسازی زمانی (Time-Series Split):** به هیچ عنوان نباید از `train_test_split` معمولی همراه با شافل (Shuffle) استفاده کرد؛ زیرا همبستگی سری زمانی باعث نشت اطلاعات آینده به گذشته (Look-ahead bias) می‌شود.
* **معماری مدل:** هایپرپارامترهای `learning_rate=0.03` و `max_depth=5` مانع از بیش‌برازش (Overfitting) روی نویز ارتعاشات آسیاب می‌شوند.
